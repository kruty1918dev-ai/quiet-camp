# QC004 — «Під кронами»

**Мета рівня:** ввести тінь — гість, що просить тінь, має стояти *усім* наметом (2×2) на затінених клітинах. Перша "особиста" побажання-позиція.

**Механіки:** + `shade` клітини (темні) + гість з `shade:true`.
**Туторіал:** `tutorial.4` — «Темні клітини позначають тінь для всього намету» (commit).

## Параметри

- Поле 5×5, вхід (4,4).
- `shade`: блок 3×2 у верхньому лівому куті — (0,0),(1,0),(2,0),(0,1),(1,1),(2,1).
- Гості: 3 — Анна, Богдан (звичайні) + Олена `shade:true`.
- `blocked`/`noise`/`friends` — немає. Освітлення: `day`.

## Розкладка (witness)

- g3 (тінь) намет (0,0) rot0 — увесь у тіні, двері (1,2) виходять на сонце.
- g1 намет (3,2) rot2 — двері (3,1).
- g2 намет (0,3) rot1 — двері (2,3), дивиться в центр.

## Чому так

Тіньова зона 3×2 дає *два* валідні місця для тіньового намета ((0,0) і (1,0))
— механіка з'являється без унікуальної головоломки, комфорт понад усе.
Інші два гості вільні — контраст: не всі клітини "особливі". Тінь в куті
поля — читабельна візуальна зона, не порізана.

**Ефект:** перше відчуття "у гостя є характер" — гра стає про піклування.
**Вигляд:** день; темніша трава під уявними кронами в куті, три палатки — одна в прохолоді, дві на сонці.

**Критерій перевірки:** witness розв'язаний; у кожному розв'язку footprint тіньового гостя ⊆ shade (перевіряється перебором); ≥2 валідних місця для тіньового намета.
