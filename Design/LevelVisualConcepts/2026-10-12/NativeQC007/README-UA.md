
# QC007: відтворення композиції в Unity

Це свіжі кадри реальної камери сцени `Camp` у Play Mode, отримані через URP
`SingleCameraRequest`. Unity 6000.6.2f1, Direct3D12 / AMD Radeon 840M.
Зображення не проходили генеративного редагування або зовнішнього розмиття.

- [Основний кадр 1536×1024](QC007-gameplay-landscape.png).
- [Широкий кадр 1920×1080](QC007-gameplay-wide.png).
- [Генеративний референс](../QC007-concept.png).

Композицію, камеру, передній план, струмок, місток, верби, очерет, світло та
розмиття країв реалізовано у виробничих компонентах рівня. Використано шість
наявних OBJ-моделей, існуючі дерева/камені AssetCatalog та CC0-рослинність гри.
Поле захищене від розмиття; колайдери декорацій видалено. Рівні й збереження
не переписуються новим оформленням; JSON гри з логічними масками не змінено.

**Збіг із AI-референсом не є точним.** Кадрування і композиційні елементи
відтворено, але відрізняються геометрія крон, фактура трави й води та м’якість
освітлення. Фінальні PNG чесно показують поточний результат рушія.
Ці кадри підтверджують роботу оформлення в Gameplay, а не мобільну продуктивність.

Джерело оформлення: `Assets/QuietCamp/Resources/QuietCamp/ArtCompositions/QC007.json`.
`tools/prepare_qc007_art.py` відтворює його із source OBJ і заданої композиції.
Ігровий renderer `QC_Renderer.asset` не редаговано; ScriptableObject-профіль
кольорокорекції створюється лише в пам’яті з JSON-параметрів.

Відтворення кадрів у вже відкритому Editor: `QC007ArtCapture` читає команду
з `Temp/ai/qc007-art-request.json`. Команди `game-start`, `game-shot`, `game-stop`
використовуються послідовно; smoke-сеанс копіює файли збереження в ignored Temp
та відновлює їх після завершення Play Mode. `capture` створює ізольований
native preview з тими ж production-компонентами, `tests` запускає EditMode
контракти оформлення, правил і історичних знімків. Нові player builds не створено.

JSON поруч із кожним PNG містить хеш зображення, хеш оформлення, версію рівня,
роздільність, параметри камери й UTC-час захоплення. Обидва кадри отримані
з відкритої копії QuietCamp; C# і JSON оформлення синхронізовані з репозиторієм.
