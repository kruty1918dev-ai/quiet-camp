# П’ять місць української долини — стан реалізації 2026-10-10

Новий світ: QC001–QC005, перспективна URP-камера, один рельєф, дорога й русло, запечені просторові частини, спільне світло та вітер. Намети й старий projected UI renderer вилучаються. Gameplay-моделі, пазли й повні дані кампанії зберігаються.

Послідовність: мозаїчна зупинка → садиба, яку пережив сад → ліс уздовж опор → переправа в очереті → пошкоджений сільський гідровузол.

Перевірено JSON Schema та portable composition: п’ять IDs, цілісні ансамблі, детермінізм, власність входів, явне проростання дерева крізь руїну, відсутність наметів, межі запуску й старий прогрес. Це перевірки даних і коду, не художнє приймання.

Native bake, дев’ять композицій, Game View інтеграція, відео руху та Low/Balanced виміри ще не виконані. На ноутбуці залишається відкритий попередній Editor; новий запуск чекає його закриття та >=1500 МБ доступної RAM. Player builds не запускаються. `QC_Renderer.asset` з користувацькою зміною не входить до commits.

Джерела: `QuietCamp/Assets/QuietCamp/Authoring/Roadmap/Composition/CinematicPilot`. Native publication: `Quiet Camp/Cinematic Roadmap/Bake Five Places`. Перевірений приватний PID/proc/network + masked-USB запуск: `bash tools/render_diorama_editor_isolated.sh --cinematic` після `--probe`.

Камера починається з FOV 30°, нахилу 48°. Ансамблі, матеріали й camera anchors потребують критичного перегляду в реальному світлі сцени. Старі зображення D01–D12 не представляють цей новий світ.
