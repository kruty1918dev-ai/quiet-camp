# Каталог нових моделей — 10 жовтня 2026

Завершено візуальний огляд усіх **1 210** джерел на 61 аркуші, з повторною
перевіркою 47 українських моделей після виправлення втрати preview матеріалу.
[Відкрити каталог](index.html) · [JSON](catalogue.json) · [CSV](catalogue.csv) ·
[Журнал спостережень](visual-review.json).

Мета: вибрати реальні моделі для 12 стильових діорам Quiet Camp і залишити
опис кожного джерела для наступної роботи. Пазли та кампанія не редагуються.

Native Editor створив 2 420 фотографій: два ракурси для всіх 1 210 FBX/OBJ,
включно з collision і LOD джерелами. Unity 6000.6.2f1, OpenGLCore,
NVIDIA GeForce 930MX. [Квитанція](native-render-receipt.json) відділяє
успішне отримання зображень від завершення їх візуального перегляду.

Повна галерея комерційних donor-моделей залишається локально в
`LocalPreviews~/`, який виключено з Git. Оригінальні моделі/архіви теж
не публікуються. Каталог описів та журнал явного візуального перегляду
зберігаються поруч. Автоматичний експорт фотографій не означає художнього
схвалення моделі.

Відтворення: `bash tools/render_diorama_editor_isolated.sh --probe`, потім
`--models`; для часткового повтору задайте `QC_MODEL_REVIEW_START` та
`QC_MODEL_REVIEW_COUNT`. `python3 tools/model_catalogue.py sheets`
створює аркуші по 20 моделей з обома ракурсами. Команда `accept` записує
явну оцінку лише після перегляду аркуша; вона не виконується автоматично.

Захист телефонних сесій: private PID/proc/network namespaces, прихований
USB; графіка через файловий X11 socket. Один Editor, workers 1/4.
Це Editor-фотографії джерел, не player build, не перевірка продуктивності
мобільного пристрою і не активація нової runtime roadmap.
Каталог містить stable GUID, оригінальний шлях/назву, SHA-256, український
опис, габарити джерела, категорію, рекомендацію застосування, матеріальний
контекст, посилання на два фото та запис перегляду. Source FBX може містити
всі LOD або кілька накладених персонажів: загальна кількість трикутників
не є вартістю однієї вибраної prefab деталізації.

Не прийняті до використання: `M0034` DamageZone (старий shader),
`M0696` та `M0820` вода Synty (OpenGL compile: дубль
`_CameraDepthTexture_TexelSize`). Неоформлені carriers/окремі mesh без
прив’язаної текстури позначені «потребує матеріалу». FX оглянуті лише як
геометрія, без перевірки анімації систем particles. Рекомендація «кандидат»
означає художню придатність, не готовність до мобільного runtime.
