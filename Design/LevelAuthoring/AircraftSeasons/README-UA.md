# Давня катастрофа й табір серед уламків

[Галерея восьми нативних кадрів](index.html): чотири сезони, загальний план і ближній огляд.

Літак має зім’яті, перекошені й частково заглиблені секції, відкриті розриви та шпангоути. Відірване крило, дрібні уламки, заглиблений ґрунтовий слід і старі зламані стовбури пояснюють катастрофу. Табір має зібраний багаж, врятовані крісла, склад, навіс із чотирма опорами, сушарку, залишений одяг, взуття й протоптані з’єднання.

## Відкрити й редагувати

**QuietCamp → Приклади → Табір між уламками → Весна / Літо / Осінь / Зима.** Кожен пункт відкриває нову чернетку; «Зберегти» створює вашу копію. Приклади в `Assets/QuietCamp/Authoring/WorldStudies/AircraftSeasons/`, в обох копіях Unity. Експорт — `Levels/<season>/`. Кампанію й пазли не замінено.

## Старіння

Виберіть декоративну packed-модель у Scene View майстерні → **QuietCamp → Інструменти → Старіння моделей**. Налаштуйте матеріал, ефект, інтенсивність, розмір ділянок, розподіл, seed і колір. Є прев’ю, скасування, збереження варіанта та Undo. Ефекти: мох, зношення фарби, сталеві іржаві ділянки, нижній бруд, алюмінієве окиснення, патьоки й старе потемніння. Оригінали не змінюються.

Кольори граней запікаються в JSON-модель: runtime не потребує нових текстур або редакторських компонентів. Наявний Polybrush лишається доступним для ручного малювання.

## Системи

`CrashMeshAuthoring` формує конструктивні пошкодження й окремі предмети. `SurfaceWeathering` запікає старіння через чинний `ModelAuthoringWorkshop`. `AircraftCrashAuthoring` читає `crash-settings.json`, формує рельєф і опори, задає історію груп. `IControlledPlacementAdapter` викликає нативний Paint PWB 4.12; фактично створені об’єкти захоплюються майстернею. `AuthoringWeatherExposure` запікає відкритість до неба; збереження й тестова гра оновлюють її після руху укриття. Експорт відтворює вже захоплену композицію точно.

Ті самі геометрія й речі зберігаються в усіх сезонах. Сніг і мокрий блиск слабші на захищених поверхнях; листя, зелень, вітер, частинки, звуки й постобробка беруться з чинних сезонних пресетів.

## Перевірка

Сім реальних циклів C01–C07 після базового C00 виконані для кожного з восьми кадрів. C08 — фінальне захоплення після виправлення контракту експорту, не додатковий художній цикл. `crash-review.json` містить дефекти й правки, `CrashVerification/` — технічні результати. 96 унікальних EditMode тестів пройшли: первинно 95/96, після виправлення експорту повторно пройшли 7 тестів його шляху. Усі чотири сезони додатково пройшли запуск звичайної гри, відтворення експорту, активні звуки й завершення еталонного рішення. Постійний прогрес, альбом і відкрита користувацька чернетка збережені без змін; результати — `CrashVerification/*-play.json` та `preservation.json`. Офлайн-галерея має дев’ять справжніх зображень, перевірені посилання, збільшення й вузький екран.

[Правила композиції](../SCENE-STORY-RULES-UA.md) обов’язкові через AGENTS.md. Статичні кадри без HUD не доводять звук або мобільну продуктивність; дрібні ручні речі розглядаються на ближньому плані. Приватний Paint API PWB перевіряється перед викликом; зміна версії потребує адаптації мосту. Атрибуція літака Poly by Google збережена в усіх експортах.
