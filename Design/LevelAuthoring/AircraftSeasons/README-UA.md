# Табір між уламками: чотири сезони

[Галерея нативних рендерів](index.html). Одна спільна композиція: поле 6×8 між двома секціями літака, лісові групи, проріджені підходи, лавка та стіл з окремими казанком і кухлем.

У Unity: **QuietCamp → Приклади → Табір між уламками → пора року**. Кожен пункт відкриває нову редаговану чернетку; «Зберегти» створює вашу копію. Файли прикладів — `Assets/QuietCamp/Authoring/WorldStudies/AircraftSeasons/*.draft.json`, в обох копіях проєкту. Експорт — `Levels/<season>/`; кампанію не замінено.

Пресети: spring_sunny, summer_day, autumn_golden, winter_snowfall. Runtime відтворює заморожену геометрію, погоду та звуки без редакторських пакетів. Атрибуція літака збережена в кожному експорті.

Результат: R08 після восьми реальних циклів, починаючи з R00. Історичні PNG, квитанції й журнал залишені для порівняння. Загальний план потрібний для фізично великого літака; маленькі ручні предмети на такому ракурсі дрібні. Кадри не є підтвердженням мобільної продуктивності.

Перевірка: 92 EditMode тести пройшли, 0 невдалих. Для кожного сезону звичайний Boot → Camp запуск із тимчасовим прогресом: геометрія відповідає чернетці, звуки відтворюються, еталонне рішення завершує пазл. Збереження й початкова чернетка користувача відновлені без змін. Офлайн-галерея перевірена на 390 px, збільшення й Esc працюють. 232 хеші джерел і 8 хешів runtime-збірок збігаються з фінальними квитанціями захоплення. Деталі — `Verification/`.
