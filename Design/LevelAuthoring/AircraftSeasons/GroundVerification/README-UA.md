# Перевірка живої поверхні — 2026-10-14

- `editmode-results.json`: 131 тест, 0 помилок; включно з усіма 100 пазлами та історичними збереженнями.
- `ground-review.json`: сім реальних циклів виправлення 14 кадрів; G08 — окремий технічний перезапис без зміни прийнятої композиції.
- `composition.json`: 14 нативних кадрів, актуальні хеші джерел і runtime DLL, відсутні shader errors, чотири точні експорти й однакові встановлені копії.
- `*-motion.json`: п’ять звичайних ігрових запусків, 38–40 фактичних кроків у кожному, рух тканини й частинок, три рівні якості, звук і розв’язання пазла. Відео без звукової доріжки.
- `motion-preservation.json`, `final-workspace-preservation.json`: прогрес, альбом і ручна чернетка редактора не змінені.
- `html-guide.json`: офлайн-зображення, п’ять відео, порівняння, збільшення, Escape й ширина 390 px.

Кадри `used` прискорюють 600 секунд симуляції маршрутів у preview. Відео не прискорюють гру. Калюжі й заглиблення — візуальний low-poly ефект без фізики рідини та зміни колізій Terrain. Зношення належить поточній сцені; після повторного відкриття рівня симуляція починається заново. FPS мобільного пристрою не вимірювався.
