# Спільна річка й берег

Джерело вимог — наданий користувачем `river_guide_download.zip`; розпакований [оригінальний гайд](river_guide.pdf). Документ є художнім орієнтиром. Його рекомендація щодо нового Shader Graph реалізується через вже встановлений Stylized Water 3: дублювати водяний шейдер не потрібно.

## Рівень спільної системи

Правки застосовуються до загального `CampArtView`, запікання MicroVerse та чинної `SeasonAtmosphereView`. Вони не прив’язані до номера рівня. Спільні параметри — `QuietCamp/Assets/QuietCamp/Resources/QuietCamp/river_environment.json`.

- `RiverSurfaceField` читає фактичні поперечні перерізи запеченої річки. Один напрям русла використовується для берега, рослинності, дощових контактів і плавучого листя. Просторові комірки обмежують пошук сусідніми сегментами.
- `RiverLandscapeGeometry` зберігає центральну криву та місця мостів, варіює ширину й краї, формує мілководдя, дно, плями вологого ґрунту та частково занурену гальку. Площадки пазла залишаються незмінними. Вихідні JSON і масиви геометрії не переписуються рендерером.
- `RiverBankEcology` використовує вже присутні моделі трави й очерету, утворює нерівномірні групи біля води та пропускає зайняті місця. Сезонний вигляд і вітер залишаються у спільних системах рослинності.
- `RiverWeatherMaterial` налаштовує власну копію Stylized Water 3: прозоре мілководдя, виразне водне тіло, широкі відблиски й локальна піна. Коефіцієнти поглинання задаються в обернених метрах: попереднє використання метрів робило русло надто прозорим. Оригінальний матеріал асета не змінюється.
- `RiverReflectionView` підключає встановлений SW3 Planar Reflection Renderer для плоскої води й одноразовий розподілений у часі cubemap оточення. Віддзеркалюється справжня геометрія сцени; вода та UI виключені. Вигнуті UV залишають рух уздовж русла. Нативний River mode вимикається лише для плоских поверхонь, бо встановлена версія шейдера не використовує в ньому planar reflections. Неплоска вода зберігає нативний режим. [Пояснення виробника щодо відображень](https://staggart.xyz/unity/stylized-water-3/sw3-docs/?section=reflection-rendering).
- `SeasonAtmosphereView` використовує справжні дощові контакти для кіл на воді. Листя рухається за кривою; біля країв сповільнюється, біля каміння відхиляється. Серпанок залежить від погоди; рідкісні риби й хвилі біля човнів мають обмежені пули. Сухі лісові локації не отримують вигаданої річки.

## Перевірка

Повний релевантний нативний набір: **173 пройшли, 0 помилок**, 376,16 с — [результат](Verification/authoring-tests-r10.json). Після останнього виправлення орієнтації нормалей — повторно **16 пройшли, 0 помилок**, 111,68 с: [перевірки водної системи](Verification/river-tests-r11.json). Вони включають усі 100 пазлів, незмінність вихідних висот і поля, коректність геометрії, напрямку течії та тангентів, рослинності й повторного застосування. Виправлена тестова ієрархія дозволяє камері повертатися окремо від світового кореня, як у справжній грі; перший невдалий прогін збережений окремо й не позначений пройденим.

[Ігрове порівняння до/після](index.html) містить чотири локації: весняну 003, літню 036, дощову 053 та зимову 088. На кожній оглянуто обидва стани гри. Цикли R01–R06, R08–R11 мають окремі зафіксовані спостереження й конкретні зміни; R07 не завершив захоплення й не зараховується. Після відгуку користувача R08–R11 додали справжні відображення, виправили згасання водяного кольору та узгодили тангенти з UV. Фінальні нативні квитанції — [R11](Verification/river-r11-native.json). Це приймання читабельності спільної води, не всіх об’єктів і камер кампанії.

[Запис у русі](Images/river-motion.mp4) — оригінальний Unity Recorder, 4,33 с, H.264 1440×1080, AAC 48 кГц. Реальне перетягування наметів і звуки чинної сцени; сторонній звук, прискорення чи монтаж не додаються. Файл повністю декодовано без помилок; [квитанція](Verification/river-motion-r11.json) містить джерела, стан відображень, аудіопакети й збереження прогресу. Переглянуто чотири часові стани запису. Це коротка перевірка руху; вона не замінює тривалого PlayMode-тесту всіх рівнів.

У R01–R04 та вихідних кадрах C01 адаптивна якість ще не була зафіксована. Від R05 якість рендера й ефектів під час захоплення фіксується на Balanced. Розмір 1440×1080 і звичайний UI однакові; проєкції камери C01/R11 порівняно точно. Не слід трактувати різницю частинок ранніх циклів як результат лише правок річки.

Спільний JSON містить ширину варіацій, глибину, берегову зону, течію, інтенсивність відображень, Fresnel, масштаб їхнього рендера, граничні кількості рослин і частинок. Для зміни геометрії вже запеченого ландшафту потрібне повторне запікання з початкового Terrain; версія запобігає повторному заглибленню. Runtime застосовує спільне оформлення до чинних незапечених старою версією русел без переписування 100 джерельних JSON.

Game View знімається у 1440×1080 з інтерфейсом: звичайне перетягування наметів, кадр із сіткою та кадр після завершення. Два PNG не називаються відео або записом звуку. Невдалі спроби не зараховуються. Для фінальних кадрів потрібні сім реальних циклів перегляду й виправлень за AGENTS.md.

Мобільний FPS і overdraw на телефоні ще не вимірювалися. Player builds не запускаються. Загальний перегляд камер і постановки 100 локацій залишається окремою незавершеною частиною роботи у `StoryCampaign/CompositionReview`.
