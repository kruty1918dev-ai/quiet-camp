# Єдина типографіка QuietCamp

Усі підтримувані мови — українська, англійська та німецька — використовують Noto Sans. Звичайний текст і заголовки мають справжні Regular/Bold накреслення однієї родини. Мова не перемикає шрифт, товщину або параметри SDF.

`CampTypography.Font` — спільна точка доступу для HTML, завантаження, приватності, відеобонусу та аварійного інтерфейсу. TMP Settings також використовує цей шрифт за замовчуванням. Літери латиниці й кирилиці запечені за однакових параметрів: 64 pt, padding 9, атлас 2048×2048. Матеріали використовують фактичні розміри атласу. Попередньо підготовлені літери зберігаються при збиранні; динамічне доповнення дозволене для решти символів. DejaVu залишається резервом для піктограм, а не для літер підтримуваних мов.

## Відтворення

Після встановлення TMP Essentials виконати **Tools → Quiet Camp → Prepare UI Fonts**. Команда створює відсутні атласи та встановлює справжнє жирне накреслення, зберігаючи GUID уже створених активів. **Setup Project** використовує той самий процес. Runtime не створює атласи для основного алфавіту й не залежить від системних шрифтів пристрою.

Джерело незмінених TTF: [Noto Fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans), commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`. Ліцензія SIL OFL 1.1 збережена як `Resources/Fonts/NotoSans_License.txt` і доступна в ігровому переліку ліцензій. Попередня атрибуція DejaVu збережена.

## Перевірка

`CampTypographyTests` перевіряє кожну локалізовану літеру й цифру в обох накресленнях, матеріали атласів, типовий шрифт TMP та справжню генерацію змішаного українського/англійського/німецького тексту без підміни родини.

2026-10-16: компіляція Unity успішна; **6/6 EditMode тестів пройшли**, без пропусків. Перевірені меню всіх трьох мов і український ігровий HUD у справжньому Game View 750×1334. Написи читаються та не обрізаються; ім’я гостя використовує NotoSans Bold SDF, підказки — NotoSans SDF. Перевірка всіх локалізованих літер не потребує резервного шрифту.

Тестовий запуск використовував лише тимчасовий прогрес у пам’яті та окремий QA-файл мови. Player builds не запускалися. Квитанції нативної перевірки збережені локально в `QA/UserSettings/Typography/`.

Порівняння підтвердило незмінність гліфів, текстур, матеріалів і GUID; повторне підготування не змінює файли. Після оптимізації повторні 6/6 тестів пройшли.
