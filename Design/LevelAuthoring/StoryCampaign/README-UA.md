## Реалізація

Система спільна з першими десятьма: редаговані JSON чернетки, PWB для характерних груп, MicroVerse/River Modeler для землі й води, наявні старіння, обростання, сезонні ефекти та жива поверхня. Новий декор не змінює логіку тіні, шуму або прохідності. Правила стилю — `../SCENE-STORY-RULES-UA.md` та `../AircraftSeasons/surface.html`.

Перед публікацією кожна нова композиція проходить щонайменше сім фактичних циклів огляду, виправлення й нативного кадру. Таблиця — план; свіжі скриншоти, перевірки та підтвердження проходження зберігаються окремо.
