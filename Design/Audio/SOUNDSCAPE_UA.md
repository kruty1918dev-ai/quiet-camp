# Звук живого кемпінгу

Звуковий простір підтримує затишок, зрозумілу взаємодію та відчуття матеріалів. Деталі з’являються через події гри, а не через кількість частинок. Вітер, дощ і багаття узгоджені з фактичним станом видимої галявини. Правила головоломки від звуку й погоди не змінюються.

## Карта звукових подій

| Ситуація | Звук і поведінка |
| --- | --- |
| Запуск гри | Вітер і негучна музика плавно набирають гучність; повторний Boot зберігає одну музичну петлю |
| Головне меню | Просторове багаття, вітер, пташки вдень, цвіркуни/сова у відповідний час |
| Стежка рівнів, налаштування, довідка | Короткий відгук керування; атмосферні акценти відпочивають, не накопичуючи чергу |
| Альбом | Власне багаття та погода активної діорами; стара діорама звільняє власні джерела; звук згасає разом із завісою перемикання |
| Вибір гостя | Відгук лише коли вибір справді змінився |
| Підняття намету | Легкий просторовий шелест біля намету |
| Перетягування | Тиха тканина залежно від швидкості, не частіше одного запиту за 0,75 с; нерухомий палець не шумить |
| Встановлення | Контакт із землею й коротке осідання тканини в місці успішної команди |
| Обертання | Варіанти короткого матеріального звуку з обмеженням частоти |
| Скасування, undo/redo, видалення | Відгук відповідної дії; невиконана команда не отримує звук встановлення |
| Помилка розміщення/перевірки | М’який короткий сигнал без різкої тривоги |
| Підказка | Тиха музична фраза з паузою між повтореннями |
| Пауза/відновлення | Короткі споріднені мотиви; музика на паузі стає тихішою |
| Завершення | Спокійне малетове співзвуччя; коротке приглушення атмосфери з плавним поверненням |
| Листяний перехід | Наявні шелест і приглушення атмосфери зберігаються; діорама не переносить джерела у наступну сцену |
| Порив вітру | Один акцент спільного WindSim, тканина намету або рослинність; щонайменше 18 с між поривами зі звуком |
| Дощ | Дифузний стереофонічний шар і окремий просторовий шар ударів по тканині, лише коли є намет |
| Дощ загасив вогонь | Один тихий шиплячий акцент біля багаття; потріскування плавно припиняється й не повертається самостійно |
| Дощ закінчився | Кілька крапель із крон протягом 12 с; паузи 3–5 с, без звуку кожної видимої краплини |
| Пташки | Кілька фраз; окремі голоси прив’язані до видимого прольоту, джерело слідує за пташкою без доплерівського спотворення |
| Втрата фокуса/фон телефону | Загальна пауза AudioListener; повернення не створює ще одну музику або чергу акцентів |

## Власність і мікс

`QuietCampBootstrap` володіє довгоживучими музикою й вітром. `CampSoundscape` володіє петлями та акцентами однієї атмосфери. Він оновлюється її єдиним циклом, отримує стан `CampWeather`/`CampRainShelter`, профіль часу доби й пориви `WindSim`. Джерела залишаються в аудіопулі; знищення діорами не знищує випадково переуспадкований AudioSource. Вимкнення власника звільняє лише його handles.

Дощ і тканина — максимум дві петлі незалежно від кількості контактів із мешами. Разом із музикою, вітром, вогнем і цвіркунами це до шести постійних джерел. Бюджет Low/Balanced/High — 8/12/16 відтворень; при заповненні тихі декоративні акценти поступаються керуванню. Наявний загальний пул допускає фонові петлі понад бюджет, тому нові постійні шари треба додавати з явним лімітом, а не довільно.

На вході 12 с без декоративних акцентів; між пташкою, совою й поривом щонайменше 3 с. Модальні вікна та переходи не отримують наздоганяючої черги. Фізичне згасання вогню й дії гравця мають окремий відгук.

Збережено регулятори Master/Music/Ambience/Effects: останній керує UI та Sfx. Reduced motion прибирає рух, але не вимикає звуки погоди. Панорама звуку слідує за ракурсом альбому; слухач розташований біля галявини, а не на віддаленій ортографічній камері.

## Ресурси й відтворюваність

Додано 14 власних процедурних WAV-майстрів: 48 kHz / 16 bit. Просторові деталі моно; дифузний дощ стерео. Довгі петлі імпортуються як streaming Vorbis, короткі деталі — PCM з попереднім завантаженням. Варіанти тканини, крапель, згасання й пташок не повторюються поспіль; відхилені запити не змінюють історію варіантів.

Дощові петлі складаються з періодичного відфільтрованого шуму та нерівномірних ударів. Для них перевіряється стрибок на стику відносно звичайних кроків сигналу. Для коротких файлів перевіряються нульові краї, DC та запас до кліпінгу. Звіти PCM не засвідчують художню якість або відсутність кліпінгу фінального сумарного міксу.

- Генератор: `tools/camp_soundscape_audio.py`; `--audit` не переписує файли.
- Unity-імпорт: `QuietCamp.Editor.SoundscapeAudioContent.Import` / меню QuietCamp → Import Soundscape Audio.
- Наявні Foley та музика: `tools/cozy_audio.py`, `CozyAudioContent.Import`.
- Наявні сторонні записи зберігають оригінальні права; нові процедурні WAV не використовують чужі записи.

## Приймання на пристрої

Автотести перевіряють gain після стартового fade, mute/unmute, один слухач, володіння джерелами альбому, зміни погоди, звільнення петель, знищення емітера, варіанти та відсутність змін у командній історії. Окремий Android-аудит перевіряє вже stripped IL2CPP-артефакти, включно з MeshCollider.

Для художнього приймання ще потрібен прохід на реальному телефоні: навушники й динамік, тихе/гучне оточення, зміна системної гучності, тривала гра, фон/повернення та навантаження на слабкому пристрої. Підтримка стерео на моно-динаміку перевіряється прослуховуванням. Дані Editor не є виміром мобільної затримки, FPS або якістю звучання динаміка.
