# Поверхні й звук біомів

`CampBiomeProfile` читає збережений опис рівня: сезон, густоту лісу, біом,
вологість і берег. Погода уточнює звук контакту з землею. Профіль якості
не змінює характер поверхні чи звукову палітру.

| Середовище | Сліди | Звукова основа та контакт |
|---|---|---|
| Весняна / літня лука | Пригнута трава, м’яка земля | Тихе шелестіння трави, приглушений контакт |
| Хвойний / густий ліс | Ґрунт на відкритому проході | Крона й хвоя, сухий ґрунт |
| Осінь | Темні відбитки серед листя | Сухе листя, рідші пташині акценти й комахи |
| Дощ або вологий ґрунт | Темніші вологі відбитки | М’який контакт із мокрою землею плюс наявні дощові шари |
| Зима | Парні сліди на снігу | Приглушений зимовий вітер, хрускіт снігу, без цвіркунів |
| Берег | Сліди залишаються на суші | Додатковий тихий просторовий шар води |

Сліди — історія вже пройденого шляху. Окремий звук поверхні лунає при
підтвердженому розміщенні / контакті намету з землею. Кожен кадр drag, undo,
відхилений drop і відновлення сесії не запускають кроки. Тканина й вітер
зберігають свої окремі звуки.

`CampGroundDetails` утримує один mesh і один освітлений матеріал для всіх слідів.
Бюджет — до 256 відбитків / 2048 трикутників. Повторна розкладка використовує
той самий mesh. Сліди читають справжні вільні маршрути evaluator і продовження
стежок, не з’являються на footprint наметів, великих перешкодах, багатті чи у воді.
Зміна розкладки перебудовує відображення, не додає команди до історії.

Проталини — частина opaque Meadow shader. До чотирьох справжніх центрів багаття,
нерівний берег снігу, волога земля, без додаткової камери, decal-pass або світла.
Центри перетворюються разом із діорамою. Тепло зберігається після згасання;
повторне засніження поля за сильного снігу займає приблизно три хвилини.
Далекі снігові пагорби та вже протоптані місця лишаються детермінованим декором.

Нові звуки — власні процедурні PCM 48 kHz: п’ять 12-секундних циклів і по три
варіанти для п’яти поверхонь. Цикли імпортуються як Streaming/Vorbis, короткі
контакти — mono PCM/DecompressOnLoad; Doppler вимкнений. Один цикл біому й один
шар води за наявності берега. Пауза, гучність, вимкнення світу й перемикання
альбому використовують наявний AudioService; власні голоси звільняються.

Відтворення ресурсів: `python3 tools/biome_audio.py`, тільки перевірка PCM:
`python3 tools/biome_audio.py --audit`. Unity-команда імпорту:
**QuietCamp → Import Biome Audio**. Генератор не завантажує сторонніх семплів,
не запускає Unity та не створює player build. PCM-аудит не замінює прослуховування
на телефоні й навушниках. Актуальні результати:
[QA-звіт](../../TestResults/biome-ground-2026-10-05/REPORT_UA.md).
