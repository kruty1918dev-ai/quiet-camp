# QuietCamp — V01 / V02

V01 залишається окремим файлом і набором авторських assets. Ревізія не
змінює кампанію й не рекламує нові механіки. Спільними залишаються нативний
Recorder, Timeline/Cinemachine, replay через CampSession і memory-only прогрес.

## Монтаж по фрагментах

| V02 | Було у V01 | Зміна й предмет уваги |
|---|---|---|
| 0–3 | П'ятисекундний загальний мотив літака | Близький розрив фюзеляжу, короткий початок із питанням про минуле місця |
| 3–6 | Контекст літака відкладався до кінця | Середній рух розкриває масштаб уламків і людські речі |
| 6–9 | Шість секунд майже нерухомої галявини | Один короткий загальний план, який дає просторовий контекст |
| 9–12 | Два намети з'являлися на віддаленому плані | Окремий кадр першого TryCommit та чинної appear-анімації |
| 12–15 | Повороту в монтажі не було | Близький кадр справжнього повороту вже встановленого намету |
| 15–18 | Наступний табір повторював попередній | Другий намет і Check завершують показану дію, а не починають схожу з нуля |
| 18–21 | Нової зупинки маршруту не було | Дерев’яна переправа розширює світ за межі трьох галявин |
| 21–24 | Вода залишалася другорядною частиною загального кадру | Окремий короткий план річки та берегової рослинності |
| 24–27 | Один віддалений дощовий план | Загальний контраст погоди підготовлює наступну деталь |
| 27–30 | Реакція тканини й землі була малою в кадрі | Ближчий намет, native краплі, контакти й колихання тканини |
| 30–34 | Шість секунд тільки погоди | Два додаткові законні розміщення й завершення табору під дощем |
| 34–38 | Повтор початкового літака | Новий об'єкт — існуючий прихисток Гавані; камера відкриває його зв'язок із табором |
| 38–42 | Від'їзд від уже знайомого фюзеляжу | Розкриття саду й заселеного табору; згасання з 40,8 с, чорний із 41,5 с |

## Однакові критерії

| Критерій | V01 | V02 |
|---|---|---|
| Загальна тривалість | 42 с | 42 с |
| Кількість монтажних планів | 7 | 13 |
| Найдовший план | 7 с | 4 с |
| Локації | QC001, QC003, QC009, Sunfield | Ті самі + переправа №36 і Гавань №100 |
| Масштаб | Переважно загальні верхні ракурси | Близький, середній, загальний; діапазон нахилів 30–61° |
| Рух | Переважно однаковий бічний дрейф | Нерухомі плани дій, наїзд, короткий супровід, відкриття |
| Дії | Розміщення й Check | Розміщення, справжній поворот, Check; більше уваги процесу |
| Дощ | Віддалений табір | Контекст → тканина й ґрунт → дія під дощем |
| Фінал | Повтор літака | Нова локація канонічної мети подорожі |
| Текст / голос / HUD | Відсутні | Відсутні |
| Походження картинки й звуку | Справжня Unity-гра | Справжня Unity-гра |

Це зміна послідовності, відбору локацій, подій та ритму, а не лише координат камер.
Зруйнований літак не падає на екрані; будинки не відбудовуються від натиску Check.
Гавань — наявний прихисток, який герої використовують, а не вигадана нова нагорода.

## Перевірка й межі

Технічні дані й хеші фінального запису — у `V02/QA_REPORT.md` та незміненій
згенерованій `V02/export-verification.json`. Художня оцінка прив'язується до
декодованих кадрів самого фінального MP4, усіх стиків і двосекундних точок.
Судження про емоційну силу монтажу є оцінкою поточного агента, а не результатом
глядацького дослідження. Мобільний FPS і вся кампанія цією ревізією не приймаються.
