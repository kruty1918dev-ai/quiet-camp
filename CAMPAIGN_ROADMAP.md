# QuietCamp — Акт 2 «Мережа місць»

## Ціль

Після 30-го рівня гра переходить від історії «ми навчилися створювати безпечні
місця» до історії «ці місця утворюють живий світ». Основна кампанія
продовжується районами, де гравець підтримує маршрути між таборами — мости,
станції, ферми, береги, покинуті поселення. Паралельно відкриваються бокові
сюжетні гілки, бонусні галявини й сезонні історії.

**Незмінна умова:** основна кампанія лишається повною сама по собі — жоден
пейвол не блокує основний шлях. Усе опційне — додаткове.

## Модель світу

- `campaign.json` → `districts[]`: `{id, act, from, to}` — діапазони позицій
  (1-базові) над `campaignLevelIds`. Порядок кампанії лишається єдиним
  джерелом істини; райони — лише назва + фрейминг.
- Акт 1 (існуючі 30): `glades` 1–10, `forest` 11–20, `embers` 21–30.
- Акт 2 (нові 12): `bridges` 31–34, `stations` 35–38, `shores` 39–42.
- Новий контент: `gen:qc_camp:21–32` — детерміновані, солвер-верифіковані,
  випікаються в `GeneratedLevels/` через `tools/regenerate_campaign.py`.
  Генератор (`CampCampaignAuthoring`) уже має «главу відновлення»
  (`storyMotifs: ruin/flowers/repaired-marker`); акт 2 додає берегові лінії
  (`Water`), зовнішні стежки (`Exterior`) й багаття (`Fire`) для нових номерів.
- Персонажі повертаються через `storyKeys` — післяклозитні картки спогадів на
  рівнях 31–42 (`journey.main.story.31–42`) згадують раніше влаштовані табори.
  Районні інтро (`district.<id>.intro`) показуються один раз при першому вході
  в непройдений район — той самий канал, що й довідник знаків.
- Наслідки рішень: нарративні (історії посилаються на пройдені місця) і
  структурні (альбом/спогади зберігають зняті табори). Гілковий стан
  рішень свідомо не вводиться — див. «Поза межами».

## Бокові маршрути

- `bonus_camps.json`: слоти отримують `levelId` → `gen:qc_camp:51–54`
  (зарезервований діапазон, окремо від кампанії). Стан відкриття —
  за пройдені рівні у відповідному десятку (`requiredCompletions`).
- 4-й слот `bonus:frostfall` — сезонний: `seasonId:"winter"` відкривається
  лише взимку (`SeasonalWindow.Now()` за метеорологічним календарем).
- `JourneyDefinition.requiredCompletions` — гілки, що відкриваються
  пройдженням: гейт `Predecessor` до досягнення N пройдених рівнів основного
  шляху. Після нього діють звичні правила: entitlement (окрема покупка),
  `currencyCost` (жаринки), `Economy.IsPro` (підписка).
- `journey.memories` «Спогади дороги» — безкоштовна бокова історія
  (`gen:qc_camp:33–35`), відкривається за пройдження (15 місць). Демонструє
  матрицю відкриттів без доданої монетизації.
- rewarded-реклама як відмикач гілок — зарезервований майбутній гак
  (`AdService` уже існує); зараз не вмикається: реальні покупки/реклама
  залишаються вимкненими (немає стора/бекенда).

## UI

- Мапа маршруту: підписи районів над першим вузлом кожного діапазону
  (`map-district`, акт 2 з відтінком `act-2`); бонус-зупинки додаються
  автоматично (RoadmapLayout).
- `JourneyPreview`: для неопублікованих/недосяжних — стан; для
  `Predecessor` + `requiredCompletions>0` — «потрібно ще місць: N».
- `BonusPreview`: рядок сезонної умови для сезонних слотів.
- Після-рівнева картка історії (`StorySummary`) показує `journey.main.story.*`
  для рівнів акту 2.

## Верифікація

- `tools/MonetizationProbe` — 42 основні + bonus + memories рівні
  (валідатор, witness, незалежний солвер), паритет локалей `district.*`.
- `tools/regenerate_campaign.py` — стейдж/випічка 49 рівнів із відкатом.
- EditMode: райони, сезонний гейт, `requiredCompletions`, `seenDistricts`.
- PlayMode: інтро району на першому рівні акту 2, бонусна зупинка після 40.

## Поза межами

- Публікація платних гілок (lighthouse/garden/station лишаються staging).
- Білди гравця (Android/iOS) — лише за явним запитом.
- Гілковий стан рішень (перманентні вибори, що змінюють карту) — окрема фаза.
