# LevelGen Samples — Ready-made Recipes

Import into your project via Package Manager → LevelGen → Samples.

| Recipe | Genre | Showcases |
|---|---|---|
| `runner_track.json` | Endless/hyper-casual runner | `segments` bands, scatter hazards, coins→entities, strict counts |
| `puzzle_board.json` | Match/puzzle board | symmetric noise painting, constrained targets, connectivity require |
| `td_lane.json` | Tower defense | winding `path` lane, tower spots, entry/exit props |
| `maze_dungeon.json` | Maze/dungeon | backtracker maze, floor invert, loot scatter |
| `campsite_board.json` | Calm puzzle camp | blocked/shade/fire layers, tent placement, overlap require |

Try them in **Tools → LevelGen → Generator Playground** — assign the TextAsset,
generate with different seeds, tweak the JSON, save the output.
