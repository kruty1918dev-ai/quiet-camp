# QuietCamp — іконка гри

Оновлено 02.10.2026. Теплий намет зі спальником, вогнище й ялини; без написів та логотипу Unity.

- `../AppIcon.png` — непрозора стандартна іконка 1024 × 1024, зі збереженим GUID.
- `quietcamp-icon-master.png` — копія стандартної іконки для експорту.
- `quietcamp-google-play-512.png` — непрозорий експорт 512 × 512.
- `quietcamp-adaptive-background.png` — непрозоре зелене тло 1024 × 1024.
- `quietcamp-adaptive-foreground.png` — прозорий передній шар 1024 × 1024 із композицією в захисній зоні.

Обидва адаптивні шари призначено для всіх шести Android-розмірів у Player Settings. **Tools → Quiet Camp → Apply App Icon** повторно призначає готові файли; перед збіркою це також робиться автоматично.

Оригінал вбудованого `image_gen`, повний промпт, посилання на специфікації та спосіб відтворення експортів: [Design/AppIcon](../../../../../Design/AppIcon/README-UA.md).
