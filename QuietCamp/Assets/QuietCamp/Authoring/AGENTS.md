# QuietCamp authoring sources

All agents must use WorldOps for campaign presentation changes. Do not manually
edit generated CampaignLevels, ArtCompositions, revisions, hashes or receipts.
Author a recipe under WorldOps/ and run `tools/qc_world.py --project <QA> run
<recipe>`. Use greenery-pilot.json before greenery-all.json for foliage changes.

The shared Editor service owns mutation, PWB placement, validation, capture,
review, publication and rollback. Extend that service for missing operations.
Pinned details, object-supported overgrowth and manually owned content must
remain protected by explicit selectors. Follow the root AGENTS.md and
Design/LevelAuthoring/WorldOps.md. User workshop editing remains available.
