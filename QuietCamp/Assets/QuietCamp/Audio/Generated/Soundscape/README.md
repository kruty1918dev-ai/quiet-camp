# Camp surface sounds

Original procedural sound design generated by `tools/camp_soundscape_audio.py`.
These files contain no downloaded or sampled third-party recordings. Existing
NaPH/UI Soundpack recordings elsewhere retain their original usage rights.

All assets are 48 kHz, 16-bit PCM source masters. The game streams Vorbis rain
loops and preloads short mono PCM details. Keep the WAV masters; import settings
belong to `SoundscapeAudioContent.Import`.

| Assets | Purpose |
| --- | --- |
| rain_canopy | Diffuse stereo rain, circular filtered texture and irregular impacts |
| rain_canvas | Mono low/mid-frequency rain impacts on tent fabric |
| fabric_gust_0–2 | Folded cloth during wind gusts and movement |
| fire_quench_0–1 | Brief ember hiss when rain extinguishes the actual fire |
| drip_0–2 | Sparse residual drops after rain |
| bird_0–2 | Soft procedural bird calls with changing phrasing |
| complete_0 | Quiet mallet resolution for a completed campsite |

Regenerate: `python3 tools/camp_soundscape_audio.py`.
Audit without rewriting: `python3 tools/camp_soundscape_audio.py --audit`.
Then run the Unity menu **QuietCamp → Import Soundscape Audio**. This upserts
only these keys and preserves the rest of the game's audio catalog.

PCM checks cover sample rates, channel counts, headroom, DC offset, one-shot
edges, and loop seam discontinuities relative to the signal's normal sample
steps. They do not replace listening on headphones and real phone speakers.
