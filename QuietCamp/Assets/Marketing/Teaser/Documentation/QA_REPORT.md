# Стан перевірки

Реалізація в роботі. Остаточний MP4 ще не записаний і не прийнятий.
До завершення потрібні: успішна компіляція в чинному Editor, пробний запис зі звуком,
перегляд усіх семи кадрів, повний запис і декодування MP4, 1260 frames / 30 FPS /
1920×1080 / stereo 48000 Hz, відсутність UI та незапланованих чорних кадрів.
Не трактувати наявність конфігурації чи receipts як успішний фінальний експорт.
