# V03 — звіт перевірки

Статус виробництва: три вступи та rough записані й переглянуті; fine проходить
окремий запис та оцінювання. Це проміжний звіт, не приймання фінального ролика.

Три вступи мають по 180 справжніх кадрів Unity Recorder. FFprobe та повне
декодування FFmpeg підтвердили 1920×1080, H.264, 30 fps, 48 kHz stereo.
Чорних кадрів і серій технічних дублікатів у цих прототипах не виявлено.
Піки декодованого звуку: A −4.94, B −6.82, C −6.18 dBFS; кліпінгу немає.
Факти, зображення й хеші — `Design/Marketing/Teaser/V03/Hooks/`.

Три focused QA-тести пройшли: відома монтажна межа/дублікати/заплановане
чорне; незаплановане чорне блокується; застаріла квитанція не пакується.
Ці синтетичні fixtures не є кадрами ролика.

102 початкові файли V01/V02, включно з двома MP4, перевірені за SHA-256
після вступних записів — без змін. Фінальну перевірку прогресу, коду,
поточних assets і художніх gates виконати після fine-запису.

## Rough: відхилено для фінального приймання

480 кадрів / 16 с / повне декодування. Чорний хвіст починається на 475 замість
474: відома похибка float32, виправлена для fine. PySceneDetect знайшов
склейку 150 та вихід 475; межі 75/210/300/360 не перевищили поріг ContentDetector.
Їх переглянуто за точними сусідніми кадрами: це близькі плани однієї сцени,
а не відсутні фрагменти. Серій ідентичних кадрів немає; рух трави не є
доказом достатньої драматургії.

| Категорія | Rough /5 | Конкретний недолік |
|---|---:|---|
| Hook, 25% | 3 | Поворот видимий, але композиція має забагато фону. |
| Зрозумілість, 25% | 3 | Геометричні підказки не пояснюють себе новачку. |
| Драматургія й фінал, 20% | 2.5 | Закриття наметів надто делікатне для кульмінації. |
| Монтаж, 15% | 3 | Маршрут зникає на стиках; масштаби стрибають. |
| Композиція, атмосфера, звук, 15% | 3 | Події звучать, але партитура слабко читається. |

Зважена оцінка **2.9/5**. Зміни fine перелічено в EDL; ці оцінки не
підміняються успішним технічним тестом. Кадри rough: `Design/Marketing/Teaser/V03/Rough/`.
