# Ціль: навчання, гайд і орієнтація гравця (QuietCamp)

Мета — щоб новачок або людина поза жанром розуміла гру без технічних термінів, у
будь-якій мові (uk/en/de), на будь-якому екрані й темпі. Гайд — це постійний
супровід, а не разовий прохід: спочатку ази, далі пояснення нових знаків тоді,
коли вони вперше трапляються в рівні (включно зі знаками з майбутніх оновлень).

Статуси: [x] реалізовано · [ ] у роботі

## Потік навчання

- [x] Навчання починається одразу з гри, а не з меню.
- [x] Автоматичний перехід у головне меню після завершення навчання (QC005).
- [x] Одноразова картка в меню: де грати («Маршрут»), що таке власний кемпінг,
      який з часом розбудовується («Мої кемпінги»).
- [x] Поступовий гайд: керовані кроки показують лише ази; коли в наступному рівні
      вперше з'являється новий знак (тінь, тиша, друзі), Остап пояснює його один
      раз і запам'ятовує назавжди. Працює для тих, хто пропустив навчання, і для
      знаків із майбутніх оновлень; мігровані сейви старих знаків не отримують.

## Реактивні підказки

- [x] Невірне розміщення (межі/накладання) → Остап пояснює помилку.
- [x] Порушення побажання (стежка/тінь/тиша/друзі) → підказка про саме ту
      помилку, ~5 с, потім повертається поточний крок.
- [x] Невдала перевірка в навчанні пояснює, чого бракує, замість покарання.

## Економіка навчання

- [x] Під час керованого навчання немає лічильників спроб і життів; перевірка
      безкоштовна й не стирає розкладку.
- [x] Пропуск навчання не забирає стартову винагороду: прапорець — подарунок,
      а не приз за проходження; повторне проходження не дублює її.

## Взаємодія з наметами

- [x] Tap-to-place: тап по вільній клітині одразу бере наступний нерозміщений
      намет і ставить його одним жестом; перетягування з картки й перенесення
      наметів лишаються, тап поза галявиною та по UI ігнорується.
- [x] Вибір намету тапом, перенесення свайпом, поворот, скасування.

## Довідник знаків

- [x] У грі є довідник усіх знаків із поясненнями: межі галявини, вільні
      клітини, стежка від дверей, тінь дерева, тиша від вогнища, друзі поруч.
      Доступ з паузи та зі списку гостей.
