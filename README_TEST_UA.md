# Quiet Camp — перевірка гри на пристрої

Це інструкція для тестування конкретної збірки, а не підтвердження готовності до випуску. Загальний стан і нові кадри — у [README](README.md); сезонне середовище — у [поточному описі рендерингу](Design/Atmosphere/SEASONAL-RENDERING-UA.md). Локальні логи, XML і результати попередніх APK зберігаються в gitignored `TestResults/` та не входять до сторінки GitHub.

## Встановлення

1. Використайте APK, зібраний із відомого commit: запишіть його hash, дату, package ID й параметри профілю. Старий файл із тією самою версією `0.1.0` не доводить наявності останніх змін. Ціль — ARM64, Android 8.0+ / API 26+.
2. Встановлюйте лише після окремого дозволу власника пристрою; не переривайте чужу ADB-сесію та не очищуйте її дані. Для ізольованої QA-збірки потрібний окремий package ID.
3. Базові головоломки працюють **офлайн**. Реальні покупки, rewarded-реклама та хмарний прогрес у поточній конфігурації не підключені.

## Керування

| Дія | Жест |
|---|---|
| Вибрати гостя/намет | Тап по картці гостя, списку гостей або намету на полі; вибір не створює хід |
| Поставити намет | Виберіть гостя, торкніться вільного місця на полі; можна утримувати й пересувати прев’ю перед відпусканням |
| Перетягнути намет | Почніть жест на поставленому наметі; після зсуву понад 8 dp з’явиться прев’ю, відпускання підтверджує хід |
| Повернути намет | Кнопка «Повернути» на панелі дій |
| Видалити намет | Кнопка «Видалити» |
| Скасувати / повторити | Кнопки Undo / Redo |
| Підказка | Кнопка «Підказка» (пояснення → область → хід) |
| Перевірити розкладку | Кнопка «Готово» |
| Пауза / назад | Кнопка паузи або Android Back |

Android Back: верхнє модальне вікно → закрити; активний preview →
скасувати; gameplay → пауза; вкладений екран → назад.

## Правила головоломки

- Намет займає footprint 2×2, двері залежать від повороту.
- Вихід за межі, перекриття та зайнятий вхід — **hard errors**, commit
  відхиляється.
- Шлях до дверей перевіряється BFS по чотирьох сусідах.
- `shade` — за маскою тіні карти; `quiet` — за відстанню до шуму;
  `friends` — за довжиною доступного шляху.
- Soft errors дозволяють зберегти розкладку, але блокують завершення.

## Тестові сценарії

Прев’ю показує місце для намету, клітину дверей і прохід від теплого маркера входу. Зелений означає виконані правила, м’який жовтий — побажання ще не виконане, помаранчевий — неможливе розміщення. Текстова плашка пояснює проблему. Невдалий жест відразу завершується й залишає попередню розкладку. Другий палець не перехоплює перенесення; перерваний системою жест скасовується.

1. **Холодний старт**: ярлик → Boot → головне меню (< 5 с).
2. **Перший рівень**: «Нова гра» → туторіал → розставити намети →
   «Готово» → екран завершення → «Далі». Завершений кемпінг залишається на екрані до натискання «Далі».
3. **Undo/redo**: поставити, перемістити, повернути, видалити —
   перевірити кожен крок скасування.
4. **Hard error**: спробувати намет на дерево/камінь — має бути відмова
   з підсвічуванням і тостом.
5. **Підказки й життя**: свіжий профіль має три підказки й п’ять життів. Підказка витрачається лише після успішного збереження. Невдалий Check списує одне життя та прибирає всі намети й undo; успішний життя не витрачає. Відмова запису не має втрачати розкладку чи ресурс. У Pro лімітів і відповідних лічильників немає.
6. **Збереження**: почати рівень, розставити частину, закрити процес,
   відкрити — «Продовжити» відновлює розкладку.
7. **Пауза/resume**: згорнути гру, розгорнути — стан зберігається.
8. **Налаштування**: змінити мову (uk/en/de), гучність, масштаб тексту,
   haptics, high contrast, reduced motion — усе застосовується й
   зберігається після перезапуску.
9. **Альбом**: після завершення рівня відкрити «Альбом» — діорама
   кемпінгу присутня.
10. **Кемпінги й подорожі**: після завершення повернутися до власного snapshot, обертати його й відкрити «Побути тут». Непубліковані подорожі та недоступний провайдер не повинні створювати платіж або право доступу.

## Матриця для перевірки

Перевірте 1080×1920, 720×1600, вузький 360 dp, landscape і tablet, uk/en/de, text scale 1.3, reduced motion та high contrast. Записуйте фактичний DPI і safe area. Editor-знімки не замінюють перевірку touch-зон, мобільного CPU/GPU, FPS, нагрівання й тривалого сеансу на телефоні.
