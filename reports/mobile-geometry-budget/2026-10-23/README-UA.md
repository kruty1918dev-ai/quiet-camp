# Мобільна геометрія: кандидат від 23.10.2026

Код оптимізації підготовлено для всіх 100 активних запечених композицій.
Це не підтверджений фінальний бюджет усіх сцен і не вимірювання FPS на телефоні.
APK/AAB не створювалися. Опубліковані JSON рівнів, ревізії, пазли, збереження,
renderer assets і старі знімки не переписувалися.

## Причини навантаження

- У вихідних 100 композиціях трава має 51 826 536 трикутників — близько 96%
  авторських моделей без землі. Кожен рівень перевищував 50 000 до
  процедурного лугу: QC001 — 564 571, максимум №44 — 837 618.
- `CoverDensity` множив щільність додаткового лугу до шести разів. У зимових
  сценах будувалася друга щільна поверхня снігу поверх існуючої землі.
- При кадрі довшому за 250 мс автоматична якість починала warmup заново.
  Постійні 3 FPS тому не могли знизити якість.
- Планарне відбиття води повторно малювало світ навіть на Low; пом'якшення
  рослинності додавало маску й повноекранний прохід.

## Зміни

`CampGeometryBudget.Prepare` створює presentation-копію під час завантаження
запеченої композиції. Той самий C# алгоритм доступний через WorldOps операцію
`scene.mobile-budget`; повторне застосування ідемпотентне. Видалення стосується
трав'яного groundcover. Дерева, квіти, головні об'єкти, рухомі моделі й
`overgrowth/` збережені. WorldOps враховує селектор, pinned і object support.

Залишено до 600 трикутників вибраних трав'яних акцентів плюс захищене
обростання. Заміна густого лугу — наявний матеріал природного ґрунту з
кольоровими плямами, витоптуванням, вологістю й снігом, та один процедурний
меш максимум на 1 200 трикутників. Далекі ділянки також отримують рідкі
акценти. Зимовий варіант використовує снігове забарвлення землі без другого
ландшафту. Нових heightfield/parallax текстур немає.

Повні прямокутні сітки землі проріджуються зі збереженням крайніх координат,
каналів і winding; нерозпізнана або вирізана геометрія залишається як є.
Фізична карта висот, вода й декоративні меші не змінюються. Геометрична
похибка спрощеної землі та контакт споруд ще потребують нативного огляду.
Повторний full-model scatter берегової трави вимкнений; дрібні камені обмежені.
Для budgeted сцен вимкнено vegetation/edge blur, місткість погодних частинок
зменшено вчетверо (максимум 400 на систему). На Low немає планарного
повторного рендеру, зберігається environment probe.

Фіксована частка авторської геометрії — 38 000; це залишає місце іншим
компонентам, але сама по собі не гарантує повний scene total.
Порушення захищеними об'єктами повертає явну помилку замість їх приховування.

## Відкриті перевірки

Unity 6000.6.2f1, його Library/Bee response files і native Editor на цій
хмарній машині відсутні. `tools/verify_monetization.py` зупинився з
`Missing existing Unity compiler response: Kruty1918.SaveSystem`.
Нові NUnit тести підготовлені, але не виконувалися в Unity.

Відомий підсумок не включає runtime rebuild річки/шахт, UI, речі гостей,
ефекти та інші завантажені світи. Зокрема старий шлях альбому з окремим
legacy-оточенням ще не покритий цим all-100 audit. Не можна переносити
його результат на будь-яку сцену чи історичний незапечений профіль.

WorldOps `maximumSceneTriangles: 50000` тепер блокує приймання, якщо сума
всіх mesh instances (також неактивних), UI та максимальної місткості
particle meshes/quads перевищує ліміт. Trails/Terrain та інша непорахована
динамічна геометрія також блокують підтвердження бюджету. Перевірка працює
для gameplay і головного меню; вона ще потребує запуску в Editor.

У вже відкритому дозволеному QA Editor, після синхронізації коду:

```sh
python3 tools/qc_world.py --project /path/to/open/QuietCamp run \
  QuietCamp/Assets/QuietCamp/Authoring/WorldOps/mobile-budget-pilot.json
# Після огляду pilot кадрів, усунення дефектів і актуального verdict:
python3 tools/qc_world.py --project /path/to/open/QuietCamp run \
  QuietCamp/Assets/QuietCamp/Authoring/WorldOps/mobile-budget-all.json
```

Обидва рецепти мають `autoApply:false`; художнє приймання не створено.
Потрібні актуальні gameplay кадри обох орієнтацій, дальні coverage зони,
перевірка землі/опор/снігу/річки та окремий профіль на Galaxy A52.
Нових знімків або підтвердження 50 000 для повної native сцени немає.
