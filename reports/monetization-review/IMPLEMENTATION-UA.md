# Поточна інтеграція: privacy7 / монетизація

База main030e76d; нова політика `2026-10-21.privacy-7-revenue`. Основна аудиторія13+. Попередній families-кандидат18+ із миттєвим безкоштовним продовженням відкликано.

`PrivacySetup` → `BootPrivacyPanel` → надійний `PrivacyInstallScope.Commit` → `GameServices`. Порядок: інформація → вік → реклама → Analytics → Crashlytics (лише доступні мети) → огляд. Немає preselection або consent-by-ack. Повернення скидає pending grants, запис із помилкою залишає дозволи закритими, старий ack без flow version не пропускає сценарій. Published consent revision включає hash документа так само, як GameServices. Bootstrap Back передається onboarding із debounce одного кадру.

`PrivacyEligibility`: Analytics/Crashlytics і звичайний рекламний opt-in від16. До13/Unknown — локально без game-side необов’язкових запитів;13–15 — лише окремо допущений явний LTD відеозапит, без фальшивої child consent. `GoogleServicesConfiguration.UnderAgeLimitedAdsAllowed` вимагає поточних published ack/hash/flow та окремих legal/config flags. `GoogleRewardedAdapter` задає Child/G для13–15, Teen/NPA для16–17, NPA за замовчуванням дорослим; PA лише за окремою дорослою feature/review. Усі живі шляхи поважають UMP CanRequestAds. LTD signal встановлюється до initialize; код видаляє лише власний попередній override, не створює consent=true. Під час старту для13–15 UMP не викликається; лише явний відеозапит. Android preference bridge не пройшов native verification.

`CampEconomy.RefreshLives`:30хв/життя, максимум5 від таймера, без урізання зароблених/куплених понад цей запас. Старий нульовий save починає таймер, не отримує миттєву спробу. Відкат/невалідний час не видає нагороди; переведення локального годинника вперед не є захищеним від читів. Pro не має ресурсних лімітів і не бачить жодних відео. `AdHintService` додає1підказку, до5на UTC-добу, за успішним reward+close, після атомарного запису. Life10/UTC-добу збережено. Pending grant при save failure повторюється без нового відео тільки поки процес працює. `RewardedVideoPresentation` блокує нижній input/audio до завершення й звільняє в finally. `GameServices.TickEconomy` перевіряє час раз на секунду, оновлює видимий таймер за зміною хвилини, без щокадрових save.

BootPrivacyPanel створюється Bootstrap: додаткової ручної scene hookup немає. Нативні layout, safe areas, Android Back, TalkBack та реальний UMP/UI ще не перевірено. Портативні тести й C#syntax не дорівнюють повній компіляції Unity.

Не додано реального Billing, не активовано qa.pro, не змінено100рівнів, renderer, художніх даних, пакетів SDK або roadmap. Purchases stay unavailable. Пакет оптимізаціїA52 окремий.
